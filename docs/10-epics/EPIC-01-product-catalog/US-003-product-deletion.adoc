==== User Story

[quote]
____
*As a* store manager, +
*I want to* delete a product from the catalog by its SKU, +
*So that* the product is no longer available for sale and is removed from all listings.
____

==== API Contract

[cols="1,3",options="header"]
|===
|Attribute |Value
|*Method* |`DELETE`
|*Path* |`/api/v1/products/{sku}`
|*Success* |`204 No Content` (empty body)
|*Not found* |`404 Not Found` + structured error body
|===

[NOTE]
The operation is *not idempotent* by design: a second `DELETE` on an already-deleted
SKU returns `404`, not `204`. This makes deletion failures explicit to callers.

==== Acceptance Criteria

[cols="1,1,4",options="header",stripes=odd]
|===
|# |Tag |Scenario

|AC-1 |`@nominal`
|*Given* the catalog contains product `TV-1` +
*When* `DELETE /api/v1/products/TV-1` is issued +
*Then* the response is `204 No Content` +
*And* a subsequent `GET /api/v1/products/TV-1` returns `404`

|AC-2 |`@error`
|*When* `DELETE` is issued for a SKU that does not exist +
*Then* the system returns `404 Not Found`

|AC-3 |`@integrity`
|*Given* products `TV-1` and `LAP-1` exist +
*When* `TV-1` is deleted +
*Then* `LAP-1` is still retrievable with `200 OK`
|===
