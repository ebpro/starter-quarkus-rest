=== US-002 — Product Retrieval

[cols="1,3",options="header"]
|===
|Field |Value
|*ID* |US-002
|*Epic* |EPIC-01 — Product Catalog
|*Actor* |Store Manager
|*Priority* |Must Have
|*Status* |icon:check-circle[role=green] Implemented & tested
|===

==== User Story

[quote]
____
*As a* store manager, +
*I want to* retrieve one or all products from the catalog, +
*So that* I can check current product details, prices, and stock levels.
____

==== API Contract

[cols="1,3",options="header"]
|===
|Attribute |Value
|*Method (list)* |`GET /api/v1/products`
|*Method (single)* |`GET /api/v1/products/{sku}`
|*Success* |`200 OK` + `ProductDTO` or `ProductDTO[]`
|*Not found* |`404 Not Found` + structured error body
|===

.ProductDTO response schema
[source,json]
----
{
  "sku":   "TV-1",
  "name":  "Television",
  "price": 499.99,
  "stock": 10
}
----

==== Acceptance Criteria

[cols="1,1,4",options="header",stripes=odd]
|===
|# |Tag |Scenario

|AC-1 |`@nominal`
|*Given* the catalog contains several products +
*When* all products are requested (`GET /api/v1/products`) +
*Then* the response is `200 OK` containing all existing SKUs

|AC-2 |`@nominal`
|*Given* a product with SKU `TV-1` exists +
*When* `GET /api/v1/products/TV-1` is requested +
*Then* the response is `200 OK` with full `ProductDTO` for `TV-1`

|AC-3 |`@error`
|*When* a GET is issued for a SKU that does not exist +
*Then* the system returns `404 Not Found`

|AC-4 |`@contract`
|*Given* products exist in the catalog +
*When* the same endpoint is called multiple times +
*Then* the JSON schema of the response body is identical on every call
|===
