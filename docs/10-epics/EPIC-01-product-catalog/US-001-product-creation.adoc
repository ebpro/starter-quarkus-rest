=== US-001 — Product Creation

[cols="1,3",options="header"]
|===
|Field |Value
|*ID* |US-001
|*Epic* |EPIC-01 — Product Catalog
|*Actor* |Store Manager
|*Priority* |Must Have
|*Status* |icon:check-circle[role=green] Implemented & tested
|===

==== User Story

[quote]
____
*As a* store manager, +
*I want to* create a product in the catalog, +
*So that* it becomes available for sale and can be retrieved by other services.
____

==== API Contract

[cols="1,3",options="header"]
|===
|Attribute |Value
|*Method* |`POST`
|*Path* |`/api/v1/products`
|*Request body* |`application/json` — `CreateProductRequest` schema
|*Success* |`201 Created` + `ProductDTO` body
|*Duplicate SKU* |`409 Conflict` + structured error body
|*Invalid payload* |`400 Bad Request` + validation error body
|===

.CreateProductRequest schema
[source,json]
----
{
  "sku":   "TV-1",       // required, non-blank
  "name":  "Television", // required, non-blank
  "price": 499.99,       // required, > 0
  "stock": 10            // required, >= 0
}
----

==== Acceptance Criteria

[cols="1,1,4",options="header",stripes=odd]
|===
|# |Tag |Scenario

|AC-1 |`@nominal`
|*Given* the catalog is empty +
*When* a valid product payload is submitted +
*Then* the system returns `201 Created` with the full `ProductDTO`

|AC-2 |`@error`
|*Given* a product with SKU `TV-1` exists +
*When* another product with the same SKU is submitted +
*Then* the system returns `409 Conflict`

|AC-3 |`@error`
|*Given* the request payload is missing required fields +
*When* the product creation request is submitted +
*Then* the system returns `400 Bad Request`

|AC-4 |`@persistence`
|*Given* product `TV-2` was created successfully +
*When* all products are retrieved +
*Then* `TV-2` is present in the response list
|===
