== EPIC-01 — Product Catalog

[.lead]
Provide a stable, versioned REST API for product lifecycle management: creation,
retrieval, and deletion — with strict consistency, structured errors, and full
traceability from requirement to passing test.

=== Objective

Enable internal and external consumers to manage a product catalog through a
predictable HTTP interface backed by a PostgreSQL datastore, within a clearly
bounded domain context.

=== Scope

[cols="1,1",options="header"]
|===
|In Scope ✅ |Out of Scope ❌

|Product creation (`POST`)
|Product update / partial patch

|Single product retrieval by SKU (`GET /{sku}`)
|Bulk import / export

|Full catalog listing (`GET /`)
|Media or asset management

|Product deletion by SKU (`DELETE /{sku}`)
|Pricing rules or promotions

|Input validation and structured error responses
|Cross-context event publishing

|URI versioning (`/api/v1/...`)
|Authentication / authorisation
|===
